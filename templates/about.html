About SkyCast

Made for the sky. Powered by data. Built to win.

The Mission

Weather is alive — deep, layered and in constant motion. SkyCast mirrors that reality in its UI: a breathing-sky background, floating parallax clouds, and frosted-glass surfaces that feel like looking at the atmosphere itself.

Behind the glass sits a simulated Hadoop / HDFS analytics engine that ingests 1.4 TB of climate history, runs MapReduce batch jobs, and serves the frontend through a Flask API — the bridge between big DATA and beautiful UI.

Tech Stack

Flask 3 Python 3.12 Tailwind CSS v4 Chart.js Hadoop / HDFS MapReduce Open-Meteo API Vanilla JS scikit-learn ReportLab RainViewer

Zero frontend frameworks. Zero build step. Pure Tailwind v4 utilities, hand-drawn SVG icons and GPU-friendly CSS animations keep this page blisteringly fast on stage.
